# Start Prompt

Work from the repository state and follow `AGENTS.md`.

When present, start project orientation at `docs/INDEX.md` and read only the
linked knowledge relevant to the request. Use the spec-driven skill for
non-trivial work; consult `docs/SPEC_DRIVEN.md` only for detailed guidance.

Behavioral novelty or conflicting authority requires explicit spec approval
before planning; a clear existing contract does not automatically require a
new spec. Every non-trivial implementation still requires proportional
`plan.md`, `tasks.md` and explicit approval of both before coding. Keep current
behavior separate from approved targets and update durable knowledge only with
supporting evidence.
